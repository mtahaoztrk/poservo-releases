# Poservo Kasa — sürümler

Bu depo yalnızca **Poservo Kasa** Windows uygulamasının kurulum ve güncelleme dosyalarını barındırır. Kaynak kod burada değildir.

- En son kurulum dosyası: [PoservoKasa-win-Setup.exe](https://github.com/mtahaoztrk/poservo-releases/releases/latest/download/PoservoKasa-win-Setup.exe)
- Kurulu kasalar güncellemeleri buradan otomatik alır.
- İlk kurulumda Windows "tanınmayan uygulama" uyarısı verebilir: **Ek bilgi → Yine de çalıştır**.
